# 避免排放量只算被取代的新品生產，乘取代率 0.5，係數取保守值，沒有係數就不計入

E6-2 的減碳量是「估算避免排放量」：重量 × 類別新品生產係數 × 取代率 R。報表並列 R = 1 的潛在值與 R = 0.5 的估算值。R 不是 1，是因為免費物品有一部分是「因為免費才拿」，沒有少買新品（WBCSD 2023 §5.1）；0.5 是 WRAP 2011 的預設值，之後用接手方問卷（Yes 1／Maybe 0.5／No 0，每類 ≥ 100 份）取代。

家具類係數取「材質組成 × 環境部材質係數」與「參考產品 EPD 的 A1–A3 平均」兩者較低者，因為兩種方法都可能高估（材質法套原生鋁、EPD 用歐洲高再生料），取較低值才不會超過任何一個獨立估計；電子產品改用 EPA WARM 產品係數，因為材質法漏掉晶片與面板製造。找不到可引用係數的類別（小家電、其他）回傳 0 並標記 `category_not_counted`，不用其他類別的值代替；找不到平均重量或平均重量不保守的類別（目前只有塑膠製品）不給預設重量，表單必填；電子產品預設重量用 UNU 指引第 3 版 2024 年平均值，並用環境部 Acer 筆電碳足跡驗證不高估。不計使用階段、處置信用與面交交通，理由與敏感度見 `docs/notes/avoided-emissions-model.md` §6–§7。

## Consequences

- 報表數字約為「每件都取代一件新品」的一半，且家具類通常低於 EPD 實測值；這是刻意的，不要改成 R = 1 或改用較高的係數。
- 改任何係數或預設值都要更新 `FACTOR_TABLE_VERSION`、方法學文件的係數表，並跑 `avoidedEmissions.test.ts`；環境部係數用 `npm run check:emission-factors` 對照 API。
- 報表頁必須同時顯示 R 與其狀態（假設／實測）、係數表版本、預設重量占比、不計入件數，以及「非碳權、不得抵減盤查」的註腳。
