# 環境部環境資料開放平臺 API v2：用法、實測與對減碳模型的用處

> **用途**：記錄環境部開放資料 API 的實際行為（文件寫的與實測不同的地方），並盤點 790 個資料集中可用來改進避免排放量模型（[avoided-emissions-model.md](avoided-emissions-model.md)）的資料。
> **實測日期**：2026-11-10，以會員 key 呼叫。key 放在 `server/.env.development` 的 `MOENV_API_KEY`（範本見 `server/.env.example`）。
> **官方文件**：Swagger 規格檔 <https://data.moenv.gov.tw/swagger/openapi.yaml>、API 使用說明 <https://data.moenv.gov.tw/paradigm>、介接服務條款 <https://data.moenv.gov.tw/api-term>、《透過 API 下載歷史資料操作手冊》112-08-22 <https://data.moenv.gov.tw/manual_file/48ea920a856be600.pdf>。

---

## 1. 基本規格

- **Base URL**：`https://data.moenv.gov.tw/api/v2/{資料集代碼}`，代碼大小寫皆可（`cfp_p_02`、`CFP_P_02`）。
- **認證**：查詢參數 `api_key`。會員在 <https://data.moenv.gov.tw/api-term> 同意條款後註冊，key 以 email 寄送，**效期一年**。
- **額度**：非會員每個 API 每日 300 次；會員每個 API 每日 5000 次（依資料集分開計）。
- **授權**：政府資料開放授權條款第 1 版（<https://data.gov.tw/license>）。
- **規模**：Swagger 共 790 個端點。分類標籤：其他 438、大氣 211、水 65、污染防治 63、地 13。前綴最多的是 `aqx`（空品）173、`stat`（統計）105、`wr`（廢棄物與回收）87、`eia`（環評）67。

## 2. 查詢參數（實測結果）

Swagger 每個端點只宣告 `language`、`offset`、`limit`、`api_key`，且**沒有回應 schema**；其餘參數只寫在手冊與說明頁。下表為 `cfp_p_02` 的實測結果。

| 參數 | 文件說法 | 實測 |
|---|---|---|
| `limit` | 上限 1000，未填預設 1000 | 相符。要求 5000 也只回 1000 |
| `offset` | 跳過筆數 | 相符。`offset=1000` 回 188 筆（全表 1,188） |
| `format` | `json`／`xml`／`csv` | JSON 是純陣列（不是 `{records: []}`）；CSV 表頭為小寫欄位名 |
| `fields` | 逗號分隔欄位 | 可用。**欄位名打錯不報錯，回 `[]`** |
| `sort` | `欄位 desc`／`欄位 asc`，預設 desc | 可用，但**所有欄位都是字串**，數值欄位排序錯誤（見 §3） |
| `filters` | `欄位,運算子,值`；同欄位多值用逗號；多條件用 `\|` | 可用，見下表 |
| `language` | `zh`／`en` | `cfp_p_02` 不支援 en，回純文字「CFP_P_02的en版本不存在」 |
| `year_month` | 歷史資料月份，如 `2020_01` | `cfp_p_02` 忽略此參數，照常回最新資料（只對有歷史資料的資料集有意義） |

`filters` 實測（`cfp_p_02`）：

| 條件 | 筆數 | 說明 |
|---|---|---|
| `announcementyear,EQ,2026` | 24 | |
| `announcementyear,EQ,2013,2026` | 87 | 同欄位多值 = OR |
| `announcementyear,GR,2025` | 77 | **`GR` 是大於等於**（不是大於；大於是 `GT`） |
| `announcementyear,GR,2025\|announcementyear,LE,2026` | 77 | `\|` = AND |
| `announcementyear,EQ,2024` | 0 | 資料集本來就沒有 2024 年記錄，不是錯誤 |
| `name,EQ,鋁錠` | 1 | 只能完全相同，沒有模糊比對 |

運算子：`EQ` 等於、`LT` 小於、`LE` 小於等於、`GR` 大於等於、`GT` 大於（手冊第 15 頁）。

## 3. 陷阱

1. **錯誤一律回 HTTP 200 加純文字**，呼叫端必須先 `JSON.parse`，失敗就當錯誤（`server/src/scripts/checkEmissionFactors.ts` 已這樣做）：
   - key 錯誤或過期：`該 API KEY 不存在或是已經到期。`
   - 額度用完：`因受限於資源分配，每日呼叫API的次數不可大於5000次。`
   - `sort` 或 `filters` 的欄位不存在：`系統發生錯誤,請稍後再試。`
   - 語言不支援：`CFP_P_02的en版本不存在`
2. **`sort` 對數值欄位做字串排序，而且像是忽略小數點**。`sort=coe desc` 前幾筆是 9.8493、9.83、9.76、957、9.56、952（像把 98493 > 983 > 976 > 957 當字串比）；真正最大值是 23800（特製液糖）。要依係數大小排序請抓回本地再排。固定位數的欄位（`announcementyear`）排序正常。
3. **欄位名稱大小寫**：資料集頁面寫 `Coe`、`Unit`、`DepartmentName`，實際回傳是全小寫（`coe`、`unit`、`departmentname`、`scpoe3_iso`）。
4. **`stat_p_*` 統計資料集的欄位是 `item1`、`value1..n`**，API 不帶欄位意義，要到資料集詳目頁查欄位說明。
5. **官方 PDF 手冊的範例網址內嵌了真實格式的 key**，不要拿來用。
6. **本機 Python 的 TLS 驗證失敗**（`CERTIFICATE_VERIFY_FAILED: self signed certificate`），curl 與 Node 用系統憑證正常；不要關閉驗證，改用 curl。

## 4. 對減碳模型有用的資料集

盤點方法：從 Swagger 790 個端點以關鍵字篩出碳足跡、自願減量與抵換、回收與廢棄物共 28 個資料集，全表抓回後逐一對照模型 §10 的缺口。

### 4.1 碳足跡

| 資料集 | 筆數 | 內容 | 對模型的用處 |
|---|---|---|---|
| `cfp_p_02` 碳足跡排放係數 | 1,188 | 材質、能源、運輸、處理服務係數 | **主要來源，見 §5.1 的修正** |
| `cfp_p_01` 台灣產品碳足跡資訊（碳標籤） | 938 | 品名、廠商、`product_carbon_footprint_data`（如「14.00kg」）、宣告單位、到期日 | **不能當生產係數**，見下 |
| `cfp_p_06` 碳足跡產品類別規則（PCR）清單 | 50 | PCR 編號、名稱、制定單位、有效期 | 只有文件清單，沒有數值 |
| `cfp_p_03` | 1 | 《自願性產品碳足跡核定標示及管理辦法》PDF 連結 | 法規 |

`cfp_p_01` 不能用的原因：
- **沒有系統邊界欄位，且多數包含使用階段**。例：中華電信 MOD 機上盒 505A 產品重 253 g，標示 39 kgCO2e／台；嘉隆工業扇 400–500 kgCO2e／台。這是搖籃到墳墓含用電，不是生產排放。
- **數值四捨五入到整數**（3.00kg、14.00kg、61.00kg），精度不足。
- **跟模型類別幾乎對不上**：938 筆中沒有椅子、桌子、櫃子或任何電腦、螢幕、印表機；家具只有蘭頓「眠豆腐」雙人獨立筒彈簧床（140、150 kgCO2e／張），家電只有燃氣熱水器與工業扇。多數是食品、清潔用品、服務。

`cfp_p_06` 的 PCR 清單有「22-040 軟包家具」「22-022 多功能事務機」「22-024 智慧型手機」「22-046 鍋具」「22-004 衣著」「22-003 梭織布料」「22-037 機器人吸塵器」「22-031 空氣清淨機」等，但 `cfp_p_01` 沒有任何依這些規則取得的碳標籤，所以目前沒有台灣產品數值可用。另外模型文件 §4.4 提到的「竹製家具 23-015」不在這 50 筆中，這份清單可能只列有效中的規則。

### 4.2 自願減量與抵換

| 資料集 | 筆數 | 內容 |
|---|---|---|
| `clim_p_11` 自願減量專案註冊 | 53 | 專案名、申請者、統編、階段、方法學編號、通過日 |
| `clim_p_12` 抵換專案註冊 | 95 | 同上 |
| `clim_p_13` 自願減量專案額度申請 | 1 | 同上加 `totalvalue`（核發額度） |
| `clim_p_14` 抵換專案額度申請 | 75 | 同上 |

方法學全部是 CDM 小型方法學（`AMS-II.C.` 需求面節能 29 件最多、`AMS-I.F.` 再生能源、`AMS-III.H.` 廢水甲烷回收、`AMS-III.Q.` 廢熱回收）、台灣自訂方法學（`TMS-*`、`TM00*`）與造林（`AR-TMS*`）。**沒有任何一件是再使用、二手交換或延長產品壽命**；名稱含「回收」的都是廢熱、甲烷或 SF6 回收。

對模型的意義：
- 沒有方法學可以借用，也沒有台灣核發過的再使用減量額度。
- 這支持 ADR 0005 的措辭立場：平台報表是「估算的避免排放量」，**不是減量額度，也不能抵換**。報表註腳可以直接寫「環境部自願減量與抵換制度目前無再使用類方法學」。

## 5. 建議

### 5.1 修正：環境部資料庫其實有 POM、ABS、PU 係數

`factorTable.ts` 的 `plastic_unspecified` 註解與模型 §4.2 寫「環境部資料庫沒有 PU 泡棉、POM、原生 ABS 係數」，但 2026-11-08 的快照裡就有這些記錄，只是用中文全名，搜英文縮寫找不到：

| 材質 | 記錄 `name` | 公告年 | 公告單位 | kgCO2e/kg | 目前以 PP 1.95 代理 |
|---|---|---|---|---|---|
| POM | 聚甲醛 | 2013 | 經濟部工業局 | 1.723 | 高估 13% |
| ABS | 丙烯腈-丁二烯-苯乙烯共聚合物 | 2025 | 環境部氣候變遷署 | 2.788 | 低估 30% |
| PU | 聚氨基甲酸乙酯樹脂 | 2025 | 環境部氣候變遷署 | 5.211 | 低估 63% |
| PU | 聚氨基甲酸乙酯樹脂 | 2015 | 環境部 | 3.17 | — |
| PVC | 聚氯乙烯 | 2025 | 環境部氣候變遷署 | 2.571 | 低估 24% |
| PE | 低密度聚乙烯(LDPE)／高密度聚乙烯(HDPE) | 2013／2023 | 經濟部工業局／環境部 | 1.9／2.21 | 約略相同 |

同一句註解說「PP 是庫內塑膠類最低值之一（LDPE 1.9、PP 1.95、EPS 1.96）」也不精確：聚甲醛 1.723 更低。

**對係數的影響**（用 `factorTable.ts` 的 BOM 重算，先確認可重現現值 3.441／1.971／2.476／1.553）：

| 類別 | 現值 | PU 取 2025 年 5.211 | PU 取 2015 年 3.17 | 實際 EF 變化 |
|---|---|---|---|---|
| 辦公椅（材質法，EPD 封頂 5.092） | 3.441 | 3.594（+4.5%） | 3.497（+1.6%） | 材質法仍低於 EPD 平均，EF 跟著變 |
| 辦公桌（EPD 1.604 為準） | 1.971 → 1.971 | — | — | 不變（BOM 沒有這幾種塑膠） |
| 金屬櫃架 | 2.476 → 2.476 | — | — | 不變（other polymers 不指名） |
| 沙發與軟墊座椅（固定 BOM，9% PUR 泡棉） | 1.553 | 1.843（+18.7%） | 1.661（+7.0%） | 直接變 |

**已採用（`FACTOR_TABLE_VERSION = "2026-11-10"`）**：新增 `polyurethane`、`polyoxymethylene`、`abs`、`pvc` 四種材質，BOM 中指名這四種塑膠的 20 個元件改用它們；PU 取 2025 年 5.211（審查 SOP「優先引用較新者」）。未指名的塑膠、彈性體與未分 LDPE／HDPE 的 PE 仍以 PP 代理。結果：辦公椅 3.441 → 3.594、沙發 1.553 → 1.843，辦公桌與金屬櫃架不變；`npm run check:emission-factors` 13 筆全部與線上 API 一致。

保留的疑慮：「聚氨基甲酸乙酯樹脂」在台灣通常指合成皮用 PU 樹脂，不是軟質泡棉，只是庫內最貼近的名稱。若改用 2015 年 3.17，辦公椅估算值低 3%（模型 §7）。辦公椅仍受 EPD 封頂；沙發是固定 BOM，沒有封頂。

### 5.4 沒有找到的

- 小家電（模型 §10.6）：`cfp_p_01` 沒有吹風機、電鍋、電扇（家用）等可用的生產排放；`cfp_p_02` 也沒有。維持不計入。
- 電子產品成品係數：`cfp_p_02` 只有 Acer 11.6 吋筆電 81 kgCO2e／台（2016）與筆電零組件（鍵盤 0.89／個、觸控板 3.06／片、電源線 0.68／條），維持用 EPA WARM。
- 台灣本地的單件預設重量：`wr_p_49` 有台數無重量、`wr_p_13` 有重量無台數，算不出來。維持用 UNU 指引。
- 辦公椅台灣品牌（模型 §10.0）：`cfp_p_01` 沒有任何椅子。

## 6. 重現

```bash
# 從 .env.development 取 key（不要印出）
KEY=$(grep -E '^MOENV_API_KEY *=' server/.env.development | sed -E 's/^[^=]*= *//; s/ *#.*$//')

# 範例：2025 年以後公告的係數，只取三欄
curl -s -G "https://data.moenv.gov.tw/api/v2/cfp_p_02" \
  --data-urlencode "api_key=$KEY" --data-urlencode "format=JSON" --data-urlencode "limit=1000" \
  --data-urlencode "filters=announcementyear,GR,2025" --data-urlencode "fields=name,coe,unit,announcementyear"
```

`cfp_p_02` 在 2026-11-10 實測時與 `docs/notes/data/moenv-cfp-p-02-2026-11-08.json` 逐筆、逐欄、同順序完全相同（1,188 筆），所以 §5 的係數都可以直接從該快照引用。
